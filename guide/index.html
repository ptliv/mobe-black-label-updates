    0BEFORE YOU START

    시작 전 준비물

    아래 다섯 가지만 있으면 돼요. 마지막 하나는 없어도 프로그램이 동작해요.

    • 윈도우 10 또는 11 PC맥북·휴대폰에서는 설치할 수 없어요.
    • 네이버 블로그 계정아이디와 비밀번호를 알고 있어야 해요.
    • 신청할 때 쓴 닉네임 + 숫자 4자리당첨 확인과 초대 코드를 받을 때 필요해요.
    • 인터넷 연결처음 켤 때와 사용하는 동안 계속 필요해요.
    • (선택) AI 키인사말·댓글을 상대 블로그에 맞게 써 줘요. 10장에서 설명해요.
    꼭 알아두기

    초대 코드와 설치 파일은 당첨자 본인만 써 주세요. 코드를 다른 사람과 나누면 그 코드는 회수될 수 있어요.

    1STEP 1 · 휴대폰 또는 PC

    당첨 확인하고 초대 코드 받기

    단톡방에 올라온 신청 페이지에서 내 결과를 확인하고, 초대 코드를 받아요. 초대 코드는 프로그램을 처음 켤 때 한 번 넣는 "열쇠"예요.

    1. 신청 페이지를 열어요

      단톡방의 신청 페이지 링크를 눌러요. 맨 위에 당첨자 명단이 보이고, 아래로 내리면 내 결과 확인이 있어요.

    2. 닉네임과 숫자 4자리를 넣어요

      신청할 때 쓴 카카오톡 닉네임과 직접 정한 숫자 4자리를 넣고 결과 보기를 눌러요.

    3. 내 번호와 초대 코드를 확인해요

      당첨이면 FOUNDERS EDITION No.○○과 MOBE-로 시작하는 긴 초대 코드가 나와요. 초대 코드 복사를 눌러 복사해 두세요. 아래 ① 사용설명서 보기는 지금 보고 있는 이 설명서이고, ② 설치 파일 받기는 2장에서 PC로 해요.

    팁 · 휴대폰에서 PC로 코드 옮기기

    휴대폰에서 확인했다면, 복사한 코드를 카카오톡 "나와의 채팅"에 붙여 넣어 보내 두세요. PC 카카오톡에서 그 메시지를 복사하면 끝이에요.

    "초대 코드를 준비하고 있어요"가 보이면

    추첨 직후 코드가 만들어지는 중이에요. 몇 분 뒤 같은 방법으로 다시 확인하면 코드가 보여요.

    2STEP 2 · PC에서

    설치 파일 받기

    여기부터는 PC에서 해요. PC 인터넷 창으로 신청 페이지를 열고 1장처럼 결과를 확인한 뒤, ② 설치 파일 받기를 누르세요. 구글 드라이브 화면이 열려요.

    1. 구글 드라이브에서 [다운로드]

      "미리보기가 없음"이라고 나와도 정상이에요. 가운데 다운로드를 눌러요. 구글 로그인은 필요 없어요.

    2. [무시하고 다운로드]

      "Google Drive가 다운로드 파일에서 문제를 감지했습니다"라는 화면이 나와요. 파일이 커서(약 215MB) 구글이 바이러스 검사를 못 한다는 뜻이에요. 무시하고 다운로드를 눌러요.

    3. 다운로드가 끝날 때까지 기다려요

      인터넷 속도에 따라 1~5분 걸려요. 파일은 보통 내 PC의 다운로드 폴더에 저장돼요. 크롬이 "흔히 다운로드되는 파일이 아닙니다"라고 하면 계속이나 유지를 눌러요.

    3STEP 3

    설치하기

    받은 파일 MOBE-BlackLabel-Setup-1.0.0.exe를 더블클릭해요. 아래 화면이 순서대로 나와요.

    1. "Windows의 PC 보호" 창이 뜨면 [추가 정보] → [실행]

      개인이 만든 프로그램이라 마이크로소프트 인증서가 없어서 나오는 안내예요. 첫 번째 그림처럼 추가 정보 글자를 누르면, 두 번째 그림처럼 실행 버튼이 생겨요.

      Windows의 PC 보호

      Microsoft Defender SmartScreen에서 인식할 수 없는 앱의 시작을 차단했습니다. 이 앱을 실행하면 PC가 위험에 노출될 수 있습니다.

      추가 정보
      실행 안 함

      Windows의 PC 보호

      Microsoft Defender SmartScreen에서 인식할 수 없는 앱의 시작을 차단했습니다. 이 앱을 실행하면 PC가 위험에 노출될 수 있습니다.

      앱:
      MOBE-BlackLabel-Setup-1.0.0.exe
      게시자:
      알 수 없는 게시자
      실행실행 안 함

      예시 그림이에요. 실제 창은 PC마다 조금 다를 수 있어요. 이 창이 안 뜨면 바로 다음 단계로 가요.

    2. 설치 옵션: 그대로 [다음 >]

      "전용 (내 이름)"이 선택된 상태 그대로 다음 >를 눌러요.

    3. 설치 위치: 그대로 [설치]

      폴더는 바꾸지 않아도 돼요. 설치를 눌러요.

    4. 설치중: 1~2분 기다려요

    5. 설치 완료: [마침]

      "MOBE BLACK LABEL 실행하기"가 체크된 채로 마침을 누르면 프로그램이 바로 켜져요. 바탕화면과 시작 메뉴에도 MOBE BLACK LABEL 아이콘이 생겨요.

    4STEP 4

    처음 켜기 · 초대 코드 넣기

    처음 켜면 검정 바탕의 초대장 화면이 나와요. 1장에서 복사한 초대 코드를 여기에 넣어요. 인터넷이 연결된 상태여야 해요.

    1. 초대 코드 칸을 눌러요

    2. 붙여 넣고 [초대장 열기]

      칸을 누른 뒤 Ctrl + V로 붙여 넣어요. 코드가 두세 줄로 보여도 괜찮아요. 초대장 열기를 눌러요.

    3. 내 에디션 번호 확인 → [시작하기]

      내 번호와 닉네임이 새겨진 화면이 나와요. 시작하기를 누르면 프로그램이 열려요. 초대 코드는 다음부터 다시 넣지 않아도 돼요.

    "유효하지 않은 초대 코드입니다"가 나오면

    코드 일부가 빠졌을 때 나와요. 결과 화면에서 초대 코드 복사로 다시 복사해서 붙여 넣어 보세요.

    PC는 2대까지

    초대 코드 하나로 PC 2대까지 쓸 수 있어요. 3번째 PC에서는 "DEVICE LIMIT" 화면이 나와요. PC를 바꿨다면 단톡방에서 모브에게 예전 PC 해제를 부탁하세요.

    5STEP 5

    설정 마법사

    처음 시작하면 "Welcome" 설정 마법사가 떠요. 네 칸을 위에서부터 채우면 바로 쓸 수 있어요. 지금 다 하기 어렵다면 나중에 하기로 닫고, 6장 방법대로 화면에서 해도 똑같아요.

    칸할 일
    1. 브라우저 준비자동으로 확인돼요. 오른쪽 위에 준비됨이 보이면 끝이에요. 작업은 이 전용 브라우저에서 따로 돌아가서, 평소 쓰는 크롬과 섞이지 않아요.
    2. AI 키 (선택)비워 둬도 돼요. 넣으면 서이추 인사말과 댓글을 상대 블로그에 맞게 AI가 써 줘요. 받는 방법은 10장에 있어요.
    3. 계정 추가네이버 블로그 ID와 내가 알아볼 이름을 넣고 계정 추가를 눌러요. 자세한 설명은 6장에 있어요.
    4. 로그인로그인 창 열기를 눌러 네이버에 직접 로그인해요. 로그인 상태 유지를 꼭 체크하세요.

    다 채웠으면 맨 아래 설정 완료를 눌러요. 마법사는 나중에 설정 탭에서 다시 열 수 있어요.

    6STEP 6

    네이버 계정 추가 · 로그인

    프로그램이 내 블로그로 일을 하려면 계정을 등록하고 한 번 로그인해 둬야 해요. 계정은 여러 개 등록할 수 있어요.

    1. 왼쪽 [+ 계정 추가]

    2. 이름과 블로그 ID를 넣고 [저장]

      오른쪽에 새 계정 창이 열려요.

      • 관리 이름: 내가 알아보기 쉬운 이름이에요. 예: 메인 블로그
      • 블로그 ID: 내 블로그 주소 blog.naver.com/ 뒤의 글자예요. 주소가 blog.naver.com/myblog_01이면 myblog_01을 넣어요.
      • 프록시: 모르면 비워 두세요. 비우면 내 인터넷으로 바로 연결돼요.
      • 서이추 하루 한도: 하루에 보낼 최대 신청 수예요. 처음엔 20 그대로 두는 걸 추천해요.

    3. 계정 카드의 [로그인하기]

      저장하면 왼쪽에 계정 카드가 생기고 로그인 필요가 보여요. 카드의 로그인하기를 눌러요.

    4. 새로 열린 창에서 네이버 로그인

      새 브라우저 창에 네이버 로그인 화면이 열려요. 아이디와 비밀번호를 직접 넣고, 아래 로그인 상태 유지를 꼭 체크한 뒤 로그인을 눌러요. 2단계 인증을 쓰면 휴대폰에서 승인해 주세요.

      비밀번호는 안전해요

      로그인은 네이버 공식 화면에서 직접 하고, 프로그램은 비밀번호를 저장하거나 어디로도 보내지 않아요. 로그인 상태만 내 PC에 남아요.

    5. 카드가 [준비됨]으로 바뀌면 끝

      로그인이 끝나면 잠시 뒤 카드에 준비됨이 떠요. 로그인 창은 닫아도 돼요. 안 바뀌면 카드의 ⋯ → 세션 확인을 눌러요. 계정이 더 있으면 1번부터 반복해요.

    7MAIN FEATURE

    서이추 자동 신청

    서로이웃 추가(서이추)는 내 블로그와 비슷한 주제의 블로그에 이웃 신청을 보내 이웃을 늘리는 방법이에요. 이웃이 늘면 내 글이 보일 기회가 넓어져요. 위쪽 서이추 탭에서 해요.

    방식 세 가지

    방식어떻게 찾나요이럴 때 좋아요
    기본검색어로 네이버 블로그 검색 결과를 훑어 블로그를 모은 뒤 신청해요.처음 시작할 때, 내 주제와 맞는 이웃을 넓게 찾을 때
    신입먹기검색 결과 중 만든 지 정한 개월 이내인 새 블로그만 골라 신청해요.서이추를 잘 받아 주는 막 시작한 블로그를 노릴 때
    파도풀이미 신청에 성공한 블로그의 이웃 목록을 따라가며 신청해요.검색어가 떨어졌을 때, 비슷한 사람끼리 이어 가고 싶을 때

    따라 하기

    1. 왼쪽에서 계정 카드를 눌러 골라요

      금색 테두리가 생긴 계정으로 신청이 나가요.

    2. 방식을 고르고 검색어를 한 줄에 하나씩

      내 블로그 주제와 맞는 단어를 넣어요. 예: 강아지 수제간식, 고양이 장난감. 신입먹기는 "개설 최대 개월"도 정해요(기본 5개월).

    3. 목표 건수를 정하고 먼저 [미리보기]

      미리보기는 신청을 보내지 않고, 어떤 블로그가 모이는지와 AI 인사말만 보여 줘요. 아래 결과 표에서 확인해 보세요.

    4. 마음에 들면 [신청 시작]

      신청은 한 건씩 20~60초 간격을 두고 천천히 나가요. 사람이 하는 것처럼 보이게 하려는 거예요. 멈추고 싶으면 중지를 눌러요.

      계정이 여러 개면 전체 계정 순차 실행으로 차례대로 돌릴 수 있어요.

    작업 중 화면

    작업용 브라우저는 작게 내려간 상태로 뒤에서 돌아가요. 다른 일을 해도 괜찮지만, 그 브라우저 창을 직접 닫지는 마세요. 화면 위쪽 금색 막대에서 진행 상황과 [중지] 버튼을 볼 수 있어요.

    저절로 멈추는 경우

    하루 한도를 다 쓰면 그날은 멈춰요. 네이버가 "하루 신청 수를 초과했다"고 하거나 확인 화면을 띄우면 계정 보호를 위해 바로 멈춰요. 다음 날 다시 하면 돼요. 상대 블로그의 이웃이 가득 차 있으면 신청할 수 없어서 자동으로 건너뛰어요.

    8AUTOMATION

    매일 자동 예약

    정해 둔 시각마다 계정을 돌아가며 서이추를 알아서 실행해요. 위쪽 스케줄 탭에서 해요.

    1. 실행 요일과 시각을 정해요

      요일을 체크하고, 시각을 고른 뒤 시각 추가를 눌러요. 예: 10:00, 14:00, 19:00. 시각 옆 ✕ 로 지울 수 있어요.

    2. 기본 실행 내용을 정해요

      방식(기본·신입먹기·파도풀), 한 번에 보낼 수(0이면 남은 한도 전부), 기본 검색어를 넣어요. 계정마다 다른 검색어를 쓰려면 오른쪽 계정 칸에 따로 적어요.

    3. 계정 순서를 정해요

      오른쪽 "계정 로테이션 순서"에서 계정을 끌어서 순서를 바꿔요. 금색 다음 차례가 붙은 계정부터 실행돼요. 로그인이 풀렸거나 그날 한도를 다 쓴 계정은 자동으로 건너뛰어요.

    4. [예약 사용]을 켜고 [저장]

      위쪽 스위치를 켜고 저장을 눌러요. 바로 한 번 돌려 보고 싶으면 지금 다음 계정 실행을 누르면 돼요.

    프로그램이 켜져 있어야 해요

    예약은 MOBE 프로그램이 켜져 있을 때만 실행돼요. PC를 끄거나 절전 모드로 들어가면 그 시각 예약은 건너뛰어요. 프로그램을 닫을 때 예약이 켜져 있으면 한 번 더 물어봐요.

    9ENGAGEMENT

    공감 · 댓글 · 스크랩

    소통하고 싶은 블로그의 글에 공감, 댓글, 스크랩을 자동으로 해 줘요. 위쪽 블로그 작업 탭에서 네 단계로 해요.

    1. 1. 대상 블로그

      블로그 ID나 주소를 한 줄에 하나씩 넣고 목록에 추가를 눌러요. 표에서 블로그마다 할 작업(공감·댓글·스크랩)과 머무는 시간을 고를 수 있어요. 바꿨으면 변경사항 저장.

    2. 2. 글 수집

      글 수집을 누르면 대상 블로그의 글 목록을 모아 와요. 특정 글만 하고 싶으면 체크하고, 아무것도 체크하지 않으면 모은 글 전체에서 골라요.

    3. 3. 작업 만들기

      작업 목록 만들기를 누르면 할 일이 만들어져요. 계정별 하루 한도와 이미 한 글은 자동으로 빠져요. 하루 목표 개수는 설정 탭에서 바꿔요.

    4. 4. 실행

      작업 실행을 누르면 한 글씩 들어가 읽는 것처럼 머물다가 작업해요. 멈추려면 작업 중지.

    스크랩 카테고리

    스크랩한 글을 내 블로그의 특정 카테고리에 넣고 싶으면, 계정 카드 ⋯ → "스크랩 카테고리 번호/이름"을 적어 두세요. 비우면 네이버 기본 카테고리로 들어가요.

    10MORE

    기록 · 설정 · AI 키

    기록 탭

    프로그램이 한 일이 쉬운 말로 시간순으로 쌓여요. 위쪽 버튼으로 서이추만, 블로그 작업만, 오류·경고만 골라 볼 수 있고 검색도 돼요. 문제가 생기면 이 화면을 캡처해서 보여 주면 빨리 해결할 수 있어요.

    설정 탭

    AI 키, 서이추 간격, 하루 최대 수, 작업할 때 머무는 시간 같은 세부 값을 바꿔요. 잘 모르겠으면 기본값 그대로 두는 게 가장 안전해요. 바꾼 뒤에는 오른쪽 위 설정 저장.

    AI 키 받는 방법 (선택)

    키쓰는 곳받는 방법
    Gemini서이추 인사말aistudio.google.com/apikey에 구글 계정으로 들어가 API 키 만들기를 눌러요. 나온 키를 복사해 설정 탭 "Gemini API 키"에 붙여 넣어요. 무료로 쓸 수 있는 범위가 있어요.
    OpenAI블로그 댓글platform.openai.com/api-keys에서 Create new secret key로 만들어요. 사용한 만큼 요금이 나가는 유료 서비스예요.

    키를 넣은 뒤 설정 탭 위쪽 Gemini 키 테스트 / OpenAI 키 테스트로 잘 되는지 확인하고 설정 저장을 눌러요. 키가 없으면 미리 준비된 기본 문구로 보내요.

    키는 비밀번호처럼

    API 키는 다른 사람에게 보여 주거나 단톡방에 올리지 마세요. 키는 내 PC에만 저장돼요.

    11SAFE USE

    안전하게 쓰는 요령

    • 처음 1주일은 천천히하루 한도를 10~20으로 두고, 블로그가 익숙해지면 조금씩 늘려요. 계정당 최대 90까지예요.
    • 간격은 기본값 그대로신청 사이 20~60초 간격이 사람처럼 보이게 해 줘요. 너무 줄이지 마세요.
    • 검색어는 내 주제와 맞게주제가 비슷한 이웃일수록 서로 소통이 잘 되고 오래 남아요.
    • 로그인이 풀리면 다시 로그인카드에 "로그인 필요"가 보이면 [로그인하기]로 다시 로그인해요.
    • 멈췄다면 다음 날네이버 제한으로 멈춘 날은 억지로 다시 돌리지 말고 다음 날 이어서 해요.
    • 계정이 여러 개라면한 PC에서 계정을 많이 돌리면 설정에 프록시를 넣는 방법도 있어요. 잘 모르면 모브에게 물어보세요.

    이럴 때이렇게 해요
    신청 페이지가 안 열려요"현재 파일을 열 수 없습니다"나 "신청을 보내지 못했어요"가 나오면, 카톡 안에서 링크를 눌러 열거나 크롬 시크릿 탭에 주소를 붙여 넣어 열어요. 폰에 구글 계정이 여러 개 로그인돼 있으면 가끔 생겨요.
    결과 확인이 안 돼요신청할 때 쓴 닉네임 그대로(띄어쓰기 포함) 넣어 보세요. 숫자 4자리를 5번 틀리면 10분 동안 막혀요.
    설치 파일이 안 받아져요2장의 [무시하고 다운로드]를 눌렀는지 확인해요. 회사 PC는 보안 정책 때문에 막힐 수 있어요.
    계정이 계속 "로그인 필요"예요로그인할 때 "로그인 상태 유지"를 체크했는지 확인해요. 계정 ⋯ → [세션 초기화] 뒤 다시 로그인해 보세요.
    예약이 안 돌았어요그 시각에 프로그램이 켜져 있었는지, PC가 절전 상태가 아니었는지 확인해요. 스케줄 탭 "최근 예약 실행"에 이유가 나와요.
    컴퓨터를 바꿨어요새 PC에 설치하고 같은 초대 코드를 넣어요. PC가 2대를 넘으면 모브에게 예전 PC 해제를 부탁해요.
    새 버전이 나왔어요따로 할 일이 없어요. 앱이 알아서 새 버전을 받아 두고 화면 위쪽에 지금 업데이트를 띄워요. 누르면 1분쯤 뒤 새 버전으로 다시 켜지고, 계정과 기록은 그대로 남아요. 다시 켜지지 않으면 바탕화면 아이콘으로 켜 주세요.
